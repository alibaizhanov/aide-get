# Get AI Data Engineer

AI Data Engineer builds and runs governed data marts in your Databricks workspace from plain-English requests.

## Install

1. In Databricks open **Workspace → Home** (your own folder), then **⋮ → Import → URL** and paste
   `https://raw.githubusercontent.com/alibaizhanov/aide-get/main/Get%20AI%20Data%20Engineer.py`
2. Open the imported notebook, paste your **license key** at the top and click **Run all** (about 10 minutes).
3. Open the link printed at the end.

If the import says "The request was invalid" or "is not absolute", the dialog was opened outside your Home folder: open Workspace → Home first and import there.

Run it as a workspace admin. To update later, open the notebook and click **Run all** again.

This notebook only downloads the release with your license key and runs its installer; everything is installed into your workspace.
